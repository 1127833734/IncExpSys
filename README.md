# 📷 收支系统（IncExpSys）

照相馆经营财务记录系统：支持门市出单、外拍出单、支出管理、按日查单与日报/月报/年报统计，同一局域网内多台电脑可共享数据。

## ✨ 功能特性

- **门市出单**：一键点击分类按钮快速出单（驾证、居住&二代证、护照、出相、拍摄社保、拍摄、斋拍、保安证、复印打印、调相回执、校卡、过塑、相架、扫描、其他）
- **外拍出单**：记录单位、税务编号、联系人、联系电话、地点、项目内容等外拍专用信息
- **自动单号**：按 `年月日-序号`（如 `20250115-003`）自动生成收入/支出单号，支持补录历史日期
- **支出管理**：租金、人工费、水费、电费、耗材开销、其他等分类，同样自动生成单号
- **查单**：按日期查看收入明细，支持按类型（门市/外拍）、分类筛选，表头点击排序，管理员可删除记录
- **报表统计**：日报（按类型/分类分组）、月报（按日汇总）、年报（按月汇总），支持类型与分类筛选
- **局域网共享**：一台电脑作为服务端存放数据，同 WiFi 下其他电脑作为客户端自动发现并连接

## 🛠 技术栈

| 部分 | 技术 |
| --- | --- |
| 后端 | Go 1.25（标准库 `net/http`，无第三方 Web 框架） |
| 数据库 | SQLite（`modernc.org/sqlite` 纯 Go 驱动，无需 CGO） |
| 前端 | 原生 HTML / CSS / JavaScript（无构建步骤，`go:embed` 打包进可执行文件） |

## 📁 项目结构

```
.
├── main.go              # 入口：模式识别、路由、启动服务
├── discovery.go         # 局域网服务端扫描
├── db/                  # 数据库初始化、建表、种子数据、模型定义
├── handler/             # HTTP 处理器（登录、收入、支出、报表）
├── middleware/          # 会话管理、登录鉴权、管理员鉴权、panic 恢复
└── web/                 # 前端页面（login.html / index.html / app.js / style.css）
```

## 🚀 快速开始

### 方式一：直接运行编译产物

双击 `收支系统.exe` 即可：

- **自动模式**：启动时会先扫描局域网，若发现服务端则作为客户端连接，否则本机作为服务端启动；
- **服务端模式**：`收支系统.exe --server`（或双击 `启动主机.bat`）；
- **客户端模式**：`收支系统.exe --client`（或双击 `启动客户端.bat`），自动搜索局域网内服务端并打开浏览器。

服务端启动后自动打开浏览器，本机访问 `http://localhost:3456`，同一局域网内其他电脑访问 `http://<主机IP>:3456`。

> 默认端口为 `3456`，可通过环境变量 `IES_PORT` 修改。

### 方式二：源码构建

```bash
# 构建（前端已通过 go:embed 打包，无需额外构建）
go build -o 收支系统.exe .

# 运行
./收支系统.exe
```

## 📊 使用说明

1. **登录**：输入工号和密码登录（普通员工仅可录入和查看，管理员可删除记录）。
2. **门市出单**：主页点击对应分类按钮 → 填写数量、金额、日期 → 出单，成功后显示自动生成的单号。
3. **外拍出单**：点击「📸 外拍」→ 填写单位、联系人、地点、项目、金额等 → 出单。
4. **查单**：点击「📋 查单」→ 选择日期查看当日收入记录，可按类型/分类筛选、点击表头排序。
5. **数据存储**：数据库文件位于可执行文件同目录下的 `data/income_expense.db`，备份该文件即可备份全部数据。

## 📦 数据说明

- 首次启动自动建表并写入收入/支出分类种子数据，旧版本数据库会自动升级（补充缺失字段）；
- 数据库使用 WAL 模式，支持并发读写。
